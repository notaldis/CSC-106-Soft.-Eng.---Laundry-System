# Team Coding Style Guide

## 1. Naming Conventions
* **HTML/CSS Files:** All lowercase, separated by hyphens (e.g., `admin-dashboard.html`).
* **Variables/Classes:** CamelCase (e.g., `activeOrder`, `customerList`).

## 2. Commit Message Format
All commits must follow this structure: `type(scope): description`
* `feat`: A new feature or screen.
* `fix`: A bug fix or typo correction.
* `docs`: Documentation changes (README, Style Guide).
* `chore`: Minor tasks like uploading images.
