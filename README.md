# Iskolar Laundry Management System

An offline digital system designed for local laundry shop staff to manage orders, track customers, and generate sales analytics without requiring an internet connection.

## Setup Instructions
1. Download the repository as a ZIP file.
2. Extract the folder to your local machine.
3. Open `login.html` in any modern web browser to view the interface.
